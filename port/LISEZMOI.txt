Analyses de sensibilite. Python 3 avec pandas, numpy, matplotlib.
  pip install pandas numpy matplotlib

            OUT_DIR  = dossier ou ecrire les resultats (sens_slopes.csv, fig02...).
Lancer : python3 sens2.py ; python3 acc.py ; python3 b1.py ; python3 b1b.py ; python3 b2.py ; python3 fig02.py
